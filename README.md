## 🚀 Featured projects

### [Smart Meter System](https://github.com/kokilan-47/Smart-Meter-System) — three-phase meter portal

A full-stack web app for monitoring three-phase electricity meters. Customers register and are **approved by an
administrator**, then see their own live usage, bills and faults; administrators manage meters, enrollments, faults
and billing.

Node.js + Express + MongoDB API with JWT sign-in, rate limiting and **16 automated tests with CI**, plus separate
React portals for customers and admins.

*Built with AI assistance — the README says exactly where and how.*

### [Nithu Institute Management System](https://github.com/kokilan-47/Nithu-Institute-Management-System) — desktop app

A JavaFX desktop application for managing students at an institute. Staff register students together with their
parent or guardian, search and edit records, and access is **role-based (Admin / Staff)** with salted PBKDF2 password
hashes. Student and parent data is saved in one MySQL transaction.

Java 17 + JavaFX + MySQL (JDBC) with Maven and JUnit 5.

### [Weather Climate Tracker](https://github.com/kokilan-47/weather-climate-tracker) — API, CLI and dashboard

A full-stack Python app that downloads **real historical weather** from the Open-Meteo API, stores it in
**PostgreSQL**, and turns it into climate statistics: monthly averages, record highs and lows, rainfall and extreme
days. Served through a REST API, a CLI and a small Chart.js dashboard.

FastAPI + SQLAlchemy, pytest suite (including a live API test) and GitHub Actions CI. No mock data.

*Built with AI assistance — the README says exactly where and how.*
