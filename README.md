## 🚀 Featured projects

### [Smart Meter System](https://github.com/kokilan-47/Smart-Meter-System) — three-phase meter portal

A full-stack web app for monitoring three-phase electricity meters. Customers register and are **approved by an
administrator**, then see their own live usage, bills and faults; administrators manage meters, enrollments, faults
and billing.

Node.js + Express + MongoDB API with JWT sign-in, rate limiting and **16 automated tests with CI**, plus separate
React portals for customers and admins.

*Built with AI assistance — the README says exactly where and how.*
